Understanding Observables

What is an Observable?

Think of an Observable as a stream of data over time, like a river flowing. You can subscribe to listen to the data, and unsubscribe to stop listening.

Key Points:

  • 📡 Observable: A source that emits data over time
  • 👂 Subscribe: Start listening to the Observable
  • 📨 next(): Receives each emitted value
  • ✅ complete(): Called when the stream finishes
  • ❌ error(): Called if something goes wrong
  • 🛑 Unsubscribe: Stop listening and cleanup resources
